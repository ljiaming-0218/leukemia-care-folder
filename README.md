# 儿童白血病就医资料夹

服务已确诊儿童白血病的患儿家庭，用同一句话说明用途：**看懂常见术语、查清医保和救助入口、整理就诊费用与申请材料**。首版把白血病科普、公开医保资料库、家庭费用与票据夹三块内容，用同一个景宁患儿家庭的虚构示例串起来；「同路人」页另收录 7 个来自已刊发报道的家庭故事，已对未成年人姓名、具体地点和精确日期做去标识化处理，演示票据仍全部是虚构数据。

本站帮助家庭整理公开资料和自家票据，不判断救助资格，也不代替官方入口；公开政策以来源原文为准。

## 90 秒演示路线

1. 首页点「用示例体验」，进入演示工作区。顶部横幅提示所有样张均为虚构数据。
2. 打开「白血病科普」：默认看到 3D 知识图谱，可直接拖动旋转视角，点「医保结算单」查看它和基本医保、电子票据、目录外自费的关系；也可用「刚确诊」「复诊前」「费用与材料」三条路径高亮阅读顺序。再切到「主题卡」，找到「骨髓检查、免疫分型、基因检测有什么区别」，复制要问医生的问题。
3. 打开「医保和救助」，先选参保地：省份选浙江、城市选丽水、区县选景宁畲族自治县（或点「用示例参保地体验」）。选到城市前页面不展示资料卡；选到景宁后显示全国 9 条、浙江 1 条和「小鹿灯」1 条。换选广东／广州时，地方细则明确显示「待核对」并给出全国查询入口。
4. 点右下角「问小助手」，问「小鹿灯能报哪些费用？」；回答会列出费用范围、申报时间、来源和提交准备入口。
5. 回到「票据导入」：四份演示原件已预填并标记为已核对，可打开原件预览、修改字段。
6. 进入「家庭费用」：住院发票与同次医保结算单归为一笔；外购药、基因检测各自独立。查看费用总额、统筹、大病、个人账户、现金和已到账救助，以及每项覆盖笔数。
7. 进入「提交准备」：查看「公告写明」与「请确认」分组、已关联原件和本页核对进度。
8. 可导出演示 CSV 或备份；演示备份只能恢复到演示工作区。
9. 打开「同路人」，在故事墙按主题筛选，点开一个家庭读长文；篇末只保留一个「去筹款准备」入口，不再把长文阅读与筹款表单混在一页。
10. 打开「筹款准备」，在「众筹准备助手」里选水滴筹或轻松筹，用演示账本生成筹款说明草稿（草稿只含分类合计与笔数，需家长补齐孩子情况和资金用途），再打开平台官方页面。本站不自动发布、不收款。

## 隐私与文件边界

- 票据识别和账本计算都在当前浏览器内完成。OCR 使用随站点发布的 Tesseract.js 中英文语言包、WASM 和 Worker，不把家长票据发送给外部识别服务。
- 原始 `File` 独立保留，下载内容与导入字节一致；旋转、放大和 OCR 只使用副本。
- 首版每批最多 20 个文件、单文件 20 MB。这是网站处理限制，不是官方申报要求。
- 没有上传接口、第三方统计或用户文件日志。真实工作区与演示工作区数据分离。
- AI 小助手不联网、不读取票据或账本；聊天内容只保留在当前页面会话中，不写入浏览器存储。请勿输入姓名、证件号、病历号或票据内容。
- 账本备份只含已确认的结构化费用、日期、类别、来源序号和核对状态，排除原件、原始文件名、OCR 全文、报告正文和身份信息；备份仍包含家庭费用，下载按钮旁有提示。演示备份带 `mode: "demo"`，不能导入真实工作区；真实备份也不能导入演示工作区。
- 下载文件名按「类别-日期-序号」生成，不含姓名和证件号。
- 当前版本没有后端持久化。票据、账本、材料关联只在当前页面会话中保留，刷新或关闭页面后需要重新导入；离开前可导出 CSV 或账本备份。
- 「说明」页的清空按钮只清空当前工作区（真实或演示），不会影响另一边。

## 科普与资料的展开层次

为避免只停留在「一句话结论」，科普页和医保资料页都分三层展开：

- **主题卡 / 资料卡**：科普七张卡各回答一个家长当下会遇到的问题，给出白话解释、一个可执行动作和原文出处；医保十一张卡写清适用地区、对象、办理入口和需要向经办方确认的问题，全国统一制度与地方已核对资料分开标注。
- **分层解释**：科普卡含 21 段展开说明，医保卡含 34 段，例如「分型和危险度分层不是一件事」「结算单上最容易看错的四组数」「备案类型决定适用情形」「时间按费用发生日期核对」。内容讲清判断依据、常见误区和家长能核对的动作，不生成治疗方案、剂量、预后数值或假定比例。
- **术语表**：58 条术语，分「疾病与分型」「检查与报告」「治疗与护理」「用药」「费用与票据」五组。每条包含白话解释、必要细节、安全提醒和来源；43 条术语可一键跳到小助手里更完整的条目。
- **3D 知识图谱**：31 个核心概念分五列排布，用 34 条有向关系说明分型、检查、治疗、用药和费用之间的阅读关系。节点以透视投影排布，可拖动旋转、调整俯仰、复位或自动旋转；点节点查看白话解释、安全提醒、来源和相连概念，选中节点的连线与相邻节点同步高亮。三条阅读路径（刚确诊／复诊前／费用与材料）可一键聚焦相关节点。按类别聚焦时，其他列降为灰色但仍保留位置，避免误以为概念消失。连线只表示阅读关系，不代表诊断结论、治疗顺序或因果。

术语支持深链，例如 `#/learn#term-mrd` 会切到术语表、展开并定位到 MRD 条目，滚动位置避开固定页头。术语卡正文为 17px，折叠标题触控高度不小于 44px。家长可在术语搜索框按术语、别名或解释文字检索。主题卡也支持深链，例如 `#/learn#questions-before-visit` 会切到主题卡并定位到对应卡片。

## AI 小助手与知识库

小助手是站内知识库问答，不是开放域大模型。知识条目来自科普卡、医保资料、小鹿灯规则、术语表、公开报道故事和本站使用说明，共 29 条、125 个索引问题；检索按关键词和中文二元组匹配，回答只组合已收录内容，并附来源和站内入口。回答分「直接结论 + 分点说明」两层，术语类问题会复用对应知识条目的分层说明。它不会生成诊断、治疗方案、剂量、预后或饮食建议；急诊症状描述会优先返回就医提示。筹款相关问题会区分官方救助与公开募捐，说明本站不收款、不自动发布，并引导到「慈善中国」等官方入口核验。

当前没有直接连接 MCP 服务：MCP 运行在服务器或本地代理侧，静态浏览器页面无法直接调用本机 MCP。首版优先保证问题不出设备，因此把知识库随站点发布并在浏览器内检索。若后续需要由云端模型查询 MCP 知识库，需要开启 Qoder Sites 后端并明确告知用户问题会离开浏览器。

## 账本口径

- 金额统一为整数分，日期为 `YYYY-MM-DD`，票号为字符串。
- 只有家长明确确认的账目进入统计；统计旁标注实际覆盖笔数。
- 费用总额、基本医保统筹、大病保险、医疗救助、个人账户、个人现金分别记录；「个人自付」「个人自费」「其他支付」保留票面原标签，各自展示，不相互叠加或按假定比例推算。
- 费用发生日期与开票日期分开保存；只有开票日期、日期不完整或冲突时标为「费用发生时间待核对」，必要时单列「日期待核对」。
- 同一份原件只能归入一笔账目；同一次住院的发票、明细和结算单可归入同一笔。重复照片、同机构同票号、同日同金额只提示，不自动合并或删除。
- 历史政策资料标记为「历史资料」，默认不列入可办理结果；缺少当地细则时显示「请向参保地医保部门或医院医保窗口确认」。

## 技术实现

- React 19 + TypeScript + Vite 8 + React Router 7（`HashRouter`），Zod 校验公开资料与备份。
- PDF.js 读取文本层和渲染扫描页；Tesseract.js + Web Worker 在浏览器内识别中英文，支持队列、取消、重试和手工修正。
- SHA-256 用于重复文件判断和备份指纹；Web Crypto 在本机计算。
- AI 小助手使用站内知识库做本地检索：29 个条目、125 个索引问题，覆盖分型、检查、治疗阶段、用药名称、医保待遇、票据字段、小鹿灯规则、公开报道故事和众筹边界，按关键词和中文二元组匹配，回答只组合已收录内容并附来源。术语定义与知识条目共用一张表，命中时合并两层解释。当前不调用外部大模型，不把问题发送到网络。
- 科普卡的分层说明、医保卡的逐项说明、58 条术语和知识图谱（31 个节点、34 条边）存于 `src/data/knowledge/` 与 `src/data/policies/`，与其他公开资料一样经 Zod 校验后随构建发布；图谱数据会检查节点和连线引用的术语 ID 是否存在。参保地三级名录存于 `src/data/regions.ts`，按 2023-06-30 区划快照生成，随资料页按需加载，不进入首屏；资料页分块约 133 kB（gzip 约 32 kB）。
- 3D 知识图谱不引入额外 3D 依赖：节点和连线由 Canvas 2D 做旋转与透视投影，节点按钮用同层 HTML 承载，保证键盘操作、44×44 触控区和读屏可用；拖动只改变视角，不改变阅读关系。
- 同路人故事存于 `src/data/stories.ts`，每条记录来源名称、原文链接、发布日期和核对日期，经 Zod 校验；众筹准备助手只读取当前工作区里家长已确认的账本汇总，在本机生成草稿，不调用平台接口、不自动发布。
- 状态按工作区模式（`real` / `demo`）分开存储，均为当前会话内存数据。
- 样式为 CSS + 系统字体，采用纸张色和墨绿强调色，标题使用系统中文宋体栈；正文 17px、行高 1.78，移动端单列、主要触控区不小于 44×44 CSS 像素、状态同时有文字和颜色、焦点可见。资料库和叙事页在桌面端控制正文宽度，避免长段落横跨整屏。

主要目录：


## 当前限制

- 数据和原件只在当前页面会话中保留，没有登录、云同步或跨设备恢复。参保地选择通过网址参数保留，刷新后仍可恢复。
- 参保地三级名录为 2023-06-30 快照，行政区划调整可能尚未反映；它只用于定位参保地，不代表当地医保待遇已收录或核对。
- 单批 20 份、单份 20 MB；OFD、HEIC 和受保护 PDF 不能预览或自动识别，但会保留原件供手工填写。
- OCR 结果依赖扫描清晰度，所有字段都需家长核对后才进入账本。
- 尚未接入支付宝、水滴筹、轻松筹或任何官方申请接口；网页只展示家长手动设置的材料状态，众筹助手只生成本地草稿并跳转平台官方页面。
- AI 小助手只覆盖站内已收录的科普、政策、小鹿灯、同路人故事和票据流程；不回答站外医学问题，不做诊断、用药、剂量、预后或饮食建议。需要开放域问答时，必须另接经过医疗审核的模型与知识库，并明确告知数据去向。
- 首次图像识别需下载约 31 MB 的中英文语言包（随站点同源发布，加载后本页复用）；PDF.js 与 Tesseract.js 已改为按需加载。
- 演示数据与演示备份仅用于功能展示，不代表任何真实家庭或机构的费用与审核结果。
- 同路人故事来自公开报道，已对未成年人姓名、具体地点和精确日期做去标识化处理；如来源方提出更正或撤回，按来源处理并更新页面。
