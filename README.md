# 骨髓小工厂

讲给 6–12 岁白血病孩子听的 3D 动态漫画科普站，家长陪读。用身体探险和短故事陪孩子看懂白血病、认识检查和治疗、练习康复、说出心里话。2026 Qoder 高校创造力大赛 Hack4Good 赛道参赛作品。

内容来自国家卫生健康委、圣犹达儿童研究医院等公开科普资料，每条都标注出处和核对日期。孩子是否患病、属于哪一型、检查报告怎么读、治疗方案怎么定，由孩子所在医院的治疗团队判断和安排。

## 快速开始（PowerShell）

```powershell
Set-Location -LiteralPath 'E:\Qoderwork\项目2'
npm install
npm run dev
```

打开 Vite 输出的本机地址（联调时使用 `http://127.0.0.1:5174/`，端口以实际输出为准）。

```powershell
npm run test
npm run build
npm run preview
```

`npm run build` 先执行 `tsc --noEmit`，再由 Vite 输出到 `dist/`。路由为 `HashRouter`，`base: './'`，可直接静态托管。

## 90 秒演示

1. 首页点「从第 1 章开始」，滚动阅读分镜，试试「暂停动画」「静态模式」和「读给我听」。
2. 打开第 3 章「工厂里出了点错」，读到「生病不是你的错，也不会传染给别人」；点漫画里的「进身体看看」跳到血管公路，再返回原分镜。
3. 打开「身体探险」，旋转骨髓工厂，点红细胞或血小板听介绍，做一道热点小问答，领取干细胞贴纸。
4. 打开「同路人」，选一篇公开报道故事，读「当时最怕什么」和「给同路人的一句话」，查看来源与去标识化说明。
5. 打开「康复建议」，选「感染预防」，读「什么时候联系医院」并勾选「已经问过医生」；再打开「心里话」，选一次情绪天气，做 3 轮吹泡泡呼吸，写一张问题卡。
6. 从「身体探险 · 血管公路」进入「巡逻小路」，用方向键走完第 1 关，展示提示、来源和「只是练习」说明。
7. 打开「大人看这里」，展示来源清单、内容边界和隐私说明。

## 内容与边界

- **8 章科普**：血液小帮手、骨髓工厂、为什么会生病、检查工具、治疗阶段、感染防护、返校、复查。每章有孩子版解释、一句话记住、大人注、来源和核对日期。
- **动态漫画**：共 74 格，每章 8–14 格；骨穿、腰穿章节首格有内容提示；针头等用温和隐喻，不画血和痛苦特写；支持键盘、静态模式和逐格文字稿。
- **3D 探险**：Three.js + React Three Fiber + Drei，程序化低多边形，不使用外部写实模型；6 个场景、26 个热点，每个热点配一段延伸解释和 2–3 选项小问答；6 张贴纸只保存场景编号。
- **巡逻小路**：3 关可解棋盘，白细胞每步一格，病菌沿红色路线前进；先站到前方路口就拦住。没有倒计时和失败惩罚，提示与来源随页展示；文案明确「只是练习」，不宣称能预防或治疗感染。
- **同路人**：故事来自已刊发报道，隐去未成年人姓名、具体地点和精确日期；每个家庭的经历作为同路人的参考，治疗安排听各自医生的；页面不设筹款和患者配对。
- **康复建议**：写观察、准备和求助提醒；具体用药和康复训练，由治疗团队或康复治疗师安排。
- **心里话**：提供表达和放松的小工具；情绪选择、问题卡和手足留言只留在当前页面；持续情绪问题可以联系治疗团队、儿童心理科／精神科或当地官方心理援助热线。
- **术语**：66 条，分属 8 章；解释里不出现治愈率、生存率、复发率、药物剂量或具体百分比。

## 隐私与本地存储

- 不需要登录，不收集姓名、年龄、医院或联系方式，不接入上传接口、第三方统计或用户行为日志。
- 只在本机保存：漫画阅读进度、章节和 3D 贴纸编号、康复卡片上的「已经问过医生」编号，以及声音／动画／省电模式开关。前两项和问诊标记可在「大人看这里」清空。
- 情绪天气、呼吸轮次、对错选择、问题卡内容、勇气贴纸选择和手足留言默认只保留在当前页面，刷新即清空；点「整理成复诊清单」时，问题会写入当前标签页的复诊草稿。
- 小游戏的通关标记、步数和关卡进度只保留在当前页面，不写入本机存储。
- 复诊准备页的草稿只写入当前标签页的 `sessionStorage`，关闭标签页即清空；页面提供一键清空。
- 朗读使用浏览器自带的语音合成，内容留在本机。
- 「同路人」只用公开报道并做去标识化，不展示真实患儿照片、学校、住址或病案号。

## 技术实现

- React 19 + TypeScript + Vite 8 + React Router 7（`HashRouter`），路由级懒加载。
- `three`、`@react-three/fiber`、`@react-three/drei`：3D 场景与词语星图单独成块，只在 `/explore`、`/words` 和章节 3D 插页加载；无 WebGL、省电模式或组件出错时，切回等价的 2D 插画、文字索引和普通按钮。
- 内容以版本化 TS 数据随构建发布，经 Zod 校验：章节、分镜、场景与热点问答、同路人、康复卡、心理工具、术语、来源。
- 动态漫画使用 CSS 动效、`IntersectionObserver` 与 Web Animations API，不引入重型动画库。
- 阅读进度、贴纸、「已经问过医生」和显示偏好等长期状态通过 `useSyncExternalStore` + `localStorage` 管理；复诊草稿通过 `sessionStorage` 管理，隐私模式写入失败时只保留当前访问。
- 样式为手写 CSS：纸张色、低饱和色块、圆角、系统字体；正文不小于 16px，主要触控区不小于 44×44 CSS 像素，焦点可见，尊重 `prefers-reduced-motion`。

## 当前限制

- 没有后端、登录或云同步；换设备或清理浏览器数据后，贴纸和问诊标记不会保留。
- 朗读音色取决于系统可用语音；部分设备可能没有中文女声，或需要联网合成。
- 3D 场景为程序化示意，细胞、器官和比例不代表真实解剖；性能目标需在真机复测。
- 同路人只摘写公开报道可核实的经过，不补写、不美化；来源方要求更正或撤回时会更新或删除。
- 康复和心理内容提供生活提醒和求助指引；具体训练与治疗，由治疗团队、康复治疗师或儿童心理科／精神科安排。
- 页面提供科普、故事、康复提醒和心理小工具；申请、支付和筹款入口留给医院与公益机构。
